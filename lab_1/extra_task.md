## 1. Исходная задача линейного программирования

Минимизировать целевую функцию:
$$Z(x) = 3x_1 + x_2 + 4x_3 + 2x_4 \to \min$$

при ограничениях:
$$
\begin{cases}
2x_1 + x_2 + x_3 \le 8 \\
x_1 + x_3 + x_4 = 5 \\
x_2 + x_4 \ge 4
\end{cases}
$$
$$x_1, x_2, x_3, x_4 \ge 0$$

Ранее в основной части работы было найдено оптимальное решение прямой задачи:
* **Оптимальная точка:** $x^* = (0, 0, 0, 5)$
* **Значение целевой функции:** $Z(x^*) = 10$

## 2. Построение двойственной задачи

Для перехода от прямой задачи на минимум к двойственной задаче на максимум применяются следующие правила:

1. **Целевая функция** двойственной задачи максимизируется, а её коэффициентами становятся правые части ограничений прямой задачи:
   $$F(y) = 8y_1 + 5y_2 + 4y_3 \to \max$$

2. **Ограничения двойственной задачи** строятся по столбцам матрицы коэффициентов прямой задачи с правыми частями, равными коэффициентам целевой функции $Z(x)$. Так как все переменные прямой задачи неотрицательны ($x_j \ge 0$), все ограничения двойственной задачи имеют знак **$\le$**:
   $$
   \begin{cases}
   2y_1 + y_2 \le 3 \\
   y_1 + y_3 \le 1 \\
   y_1 + y_2 \le 4 \\
   y_2 + y_3 \le 2
   \end{cases}
   $$

3. **Знаки двойственных переменных** $y_i$ определяются знаками соответствующих ограничений прямой задачи (для задачи на минимум):
   * 1-е ограничение ($\le 8$) $\implies y_1 \le 0$
   * 2-е ограничение ($= 5$) $\implies y_2 \in \mathbb{R}$ (без ограничений на знак)
   * 3-е ограничение ($\ge 4$) $\implies y_3 \ge 0$

### Математическая модель двойственной задачи:
$$F(y) = 8y_1 + 5y_2 + 4y_3 \to \max$$
при условиях:
$$
\begin{cases}
2y_1 + y_2 \le 3 \\
y_1 + y_3 \le 1 \\
y_1 + y_2 \le 4 \\
y_2 + y_3 \le 2
\end{cases}
$$
$$y_1 \le 0, \quad y_2 \in \mathbb{R}, \quad y_3 \ge 0$$

## 3. Решение двойственной задачи через теоремы двойственности

Используем оптимальный план прямой задачи $x^* = (0, 0, 0, 5)$ и **вторую теорему двойственности (теорему о дополняющей нежесткости)**.

### Шаг 1. Анализ ограничений прямой задачи
Подставим $x^* = (0, 0, 0, 5)$ в ограничения исходной задачи:
1. $2(0) + 0 + 0 = 0 < 8$ — условие выполняется как строгое неравенство, следовательно, соответствующая двойственная переменная равна нулю:
   $$y_1^* = 0$$
2. $0 + 0 + 5 = 5$ — ограничение-равенство выполняется.
3. $0 + 5 = 5 > 4$ — условие выполняется как строгое неравенство, следовательно, соответствующая двойственная переменная равна нулю:
   $$y_3^* = 0$$

### Шаг 2. Анализ переменных прямой задачи
В оптимальном плане прямой задачи переменная $x_4^* = 5 > 0$. По теореме о дополняющей нежесткости, 4-е ограничение двойственной задачи должно обращаться в строгое равенство:
$$y_2^* + y_3^* = 2$$

Подставляя $y_3^* = 0$, находим:
$$y_2^* = 2$$

### Шаг 3. Проверка допустимости найденного решения
Подставим $y^* = (0, 2, 0)$ в систему ограничений двойственной задачи:
* $2(0) + 2 = 2 \le 3$ — выполняется;
* $0 + 0 = 0 \le 1$ — выполняется;
* $0 + 2 = 2 \le 4$ — выполняется;
* $2 + 0 = 2 \le 2$ — выполняется.

Условия на знаки переменных ($y_1^* = 0 \le 0$, $y_3^* = 0 \ge 0$) также выполнены. Значит, $y^* = (0, 2, 0)$ — допустимый план.

### Шаг 4. Вычисление значения целевой функции и проверка
$$F(y^*) = 8(0) + 5(2) + 4(0) = 10$$

По **первой теореме двойственности** оптимальные значения целевых функций прямой и двойственной задач совпадают:
$$\min Z(x^*) = \max F(y^*) = 10$$

---

## 4. Ответ

* **Оптимальная точка двойственной задачи:** $y^* = (0, 2, 0)$
* **Максимальное значение целевой функции:** $F(y^*) = 10$
